# Planet Asset Generator

`generate_planet_assets.py` cooks the terrestrial-planet proof assets. It requires Python 3 and no third-party
packages. The fixed seed, algorithm version, texture dimensions, and mesh density make the output repeatable. The
generator synthesizes every pixel and vertex; it consumes no external maps or source imagery.

The iconic processed presentation of NASA Apollo 17 frame `AS17-148-22727` is the visual target for composition,
color hierarchy, cloud structure, and limb treatment. The generator uses coarse hand-authored geography plus
procedural detail. The NASA photograph supplies no production pixels or map data.

Run the generator from the repository root:

```sh
python3 Tools/PlanetAssetGenerator/generate_planet_assets.py
```

The generator writes these files under `Engine2/Game Content/Planet/Assets/`:

- `TerrestrialPlanetElevation.png`: 1024×512, 16-bit linear grayscale. Sample 32768 is sea level; lower and higher
  samples are ocean depth and land elevation.
- `TerrestrialPlanetSurface.png`: 1024×512 RGBA8. RGB is authored sRGB surface color. Alpha is a binary land mask.
- `TerrestrialPlanetControl.png`: 1024×512 linear RGBA8. The channels are moisture, vegetation, ice or snow, and
  perceptual roughness.
- `TerrestrialPlanetClouds.png`: 1024×512 linear RGBA8. The channels are coverage, density, detail, and coverage.
- `TerrestrialPlanet.usda`: unit-radius 256×128 UV sphere with positions, outward normals, and texture coordinates.
- `TerrestrialPlanet.usdz`: uncompressed, 64-byte-aligned package containing the same USDA layer.
- `TerrestrialPlanetManifest.json`: seed, formats, channel contracts, content metrics, and SHA-256 digests.

All texture fields are evaluated on the unit sphere at periodic pixel centers. Sampling with longitude wrap therefore
crosses the first and last columns without an authored discontinuity. The generator rejects output that misses the
required land, vegetation, ice, mountain, or cloud coverage ranges, or whose longitude boundary differs materially
more than ordinary adjacent columns. Global surface fractions use cosine-latitude weighting so equirectangular polar
rows do not overstate their share of the sphere.

Validate checked-in output without changing it:

```sh
python3 Tools/PlanetAssetGenerator/generate_planet_assets.py --check
```

The check recooks the complete output in a temporary directory and compares every generated byte with the checked-in
files. It also verifies every manifest digest, PNG dimensions and channel formats, decoded scanline layout, longitude
continuity, content metrics, USDZ storage mode, 64-byte payload alignment, and byte equality between the USDA source
and packaged layer.
